Foundations & components

Trust furniture is product UI, so it gets real components.

Everything here resolves to a Classical token. The one deliberate extension is the posture ramp, because the system is mono and this product has to encode five mutually exclusive legal states without inventing five hues. Load styles.css then pml.css; use the classes below rather than restyling.

01

Type

Cormorant Garamond over Lora, straight from the tokens. Nothing here sets bold; weight is carried by size and rule, italics by case names.

Rules

Case captions are always italic. Docket numbers, dates, figures and any column of numerals set tabular (.num). Section labels use .kicker — 11px, .16em tracking, uppercase.

Minimum body size is 12.5px, and only for metadata. Legal text never goes below 13px.

02

Colour

Classical is mono gold. Posture is therefore encoded as depth, not hue — one perceptual axis, five steps, dark meaning worse for platforms.

Posture ramp

Generated in OKLCH on the neutral hue at fixed lightness steps, so a state's fill can also take its circuit's hue on the map without breaking the ordering.

Never used alone. Every posture fill is accompanied by its label, and the legend appears above any surface that uses it.

Operational status

A separate axis from posture, and they can disagree — a state can be heading for the platforms on the law and still be closed today. Status uses texture rather than depth so the two never blur: outline for go, hatch for restricted, solid ink for banned.

Go Restricted Banned updated Circuit hue is applied only on the map, from a 13-step low-chroma wheel; it never appears in text or chrome.
03

Spacing & structure

The Classical scale at 1.15× density. Sections are separated by hairlines, not cards; panels are bordered and unfilled.

Rules

Page gutter --space-6, section padding --space-8 top and bottom with a 1px divider between. Panel padding --space-4. Table rows 9px vertical.

Two-pane surfaces are 1.5fr / 1fr, except cases, which run 1fr / 3fr because the record carries prose. Everything collapses to one column at 940px.

04

Components

Twelve pieces carry the whole product. Trust furniture is half of them, by design.

ProvenanceLabel

Frozen at publish time and shown at the point of use, never in a footer. Human approval is a filled dot; agent approval is a hollow dot on a dashed border, so the weaker claim looks weaker.

Human-approved Agent-approved · gate-v2.1 ⚠ General legal information — not legal advice

NotLiveDraftBanner

The most important state in the system. A draft must be impossible to mistake for published tracker content, so it carries a hatched edge, a dashed rule, and the words in full — three signals, none of them colour alone.

RunStatusChip & origin flag

Seven run outcomes, all first-class. A boring run is evidence too — an empty run gets the same treatment as a publish, because hiding them would make the log a highlight reel.

Diff

Every human edit to an agent draft is published side by side, original left and published right. Struck text is what the operator removed; underscored text is what they wrote.

Agent draft

Utah has banned prediction markets.

Published after operator edit

Utah has entered summary judgment for the State; sports event contracts are unavailable.

Empty states

Written, not generic. Each says what happened, what it means, and what it is not — an untracked state is not a finding of legality, and an unrun eval is not a passing eval.

No material change The run completed and proposed nothing. Sources were checked and matched the published record. Empty runs are kept in the log deliberately.
Evals not run This run predates the eval suite. The field is empty rather than zero. An empty eval is not a passing eval.
No tracked activity Nothing in this state has been reviewed. Absence of a finding is not a finding of legality.

Tables

Hairline rules, uppercase heads, sortable where the column is ordinal. Selection is an accent inset on the first cell with matching padding, so nothing under it is obscured.
